# Cloud Cost Management - Demo Walkthrough Script

## 1. How to Start (Run Without `--reload`)
- **Backend**: `cd backend; .\venv\Scripts\python.exe -m uvicorn main:app --host 127.0.0.1 --port 8000`
- **Frontend**: `cd frontend; npm run dev`
- **Reset Demo State**: Restart the backend before each presentation.

---

## 2. Five-Minute Presentation Walkthrough
1. **Account Selector**: Open top navbar dropdown and select **Demo AWS**.
2. **Dashboard**: Show overview KPIs — note the **Simulated** badge, potential savings (idle resources + commitment plans), and high-priority recommendations count.
3. **Anomalies**: Navigate to **Anomalies** to view the detected EC2 cost spike ($z = 14.00$, critical severity) flagged by residual analysis.
4. **Recommendations**: Review idle instance, right-sizing, and Savings Plan recommendations generated by the advisor.
5. **Remediation & Escalation (HELD)**: Click **Fast-Forward** on Remediation status — action is held (**HELD**) due to the active unresolved critical anomaly.
6. **Resolve Anomaly**: Return to **Anomalies**, click **Resolve** on the critical anomaly.
7. **Fast-Forward (Execution)**: Return to **Remediation** and trigger Fast-Forward again — the safety check passes and simulated instance stop executes.
8. **What-If Simulations**: Navigate to **What-If**, click **Simulate All** to project 30-day baseline vs post-action costs with uncertainty bands.
9. **ML Predictions**: Review cost forecasts comparing Holt's Double Exponential Smoothing and Polynomial Regression with MAPE metrics.
10. **Demo Azure**: Switch dropdown to **Demo Azure** to inspect multi-cloud VM inventory, idle VM detection, and forecasts.
11. **Real AWS Account**: Switch dropdown to **Real AWS (`4d62c035`)** to verify live scanned EC2 and S3 resources and real inventory ingestion.

## 3. Known Limits
- **Simulated Remediation**: Resource stops/resizes are simulated and logged; no live cloud resources are modified or terminated.
- **Azure Scope**: Azure collection currently supports Virtual Machines (AzureVM); storage and serverless services are not collected.
- **Synthetic Demo Data**: Demo account histories are synthetic seeds and explicitly labelled as "Simulated".
- **List-Price Estimation**: AWS costs use public list prices and exclude enterprise discounts, taxes, or reserved credits.
- **Idle Runtime Threshold**: Real idle detection requires 168 hours of runtime history (the live EC2 instance reaches this ~27 Oct).
- **Single Region**: Live AWS scanning is currently restricted to `us-east-1`.
- **Demo Reset**: Restarting the backend process resets demo accounts and re-arms the demo story.
